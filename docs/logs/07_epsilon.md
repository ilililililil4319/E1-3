## data.json 점수를 == 비교 vs epsilon 비교

== 와 > 로 비교하면 1e-16 수준의 오차가 승패를 정한다. epsilon 비교는 '사실상 같다'고 보고 UNDECIDED 로 둔다.

```console
$ python3 -c 'import json
from app.mac import mac
from app.judge import judge
d = json.load(open("data.json", encoding="utf-8"))
print("케이스      Cross점수            X점수                단순비교 epsilon비교")
for k, v in d["patterns"].items():
    n = int(k.split("_")[1]); f = d["filters"]["size_%d" % n]
    a, b = mac(v["input"], f["cross"]), mac(v["input"], f["x"])
    naive = "Cross" if a > b else ("X" if b > a else "UNDECIDED")
    print("{:<11} {:<20} {:<20} {:<8} {}".format(k, repr(a), repr(b), naive, judge(a, b, "Cross", "X", "UNDECIDED")))'
케이스      Cross점수            X점수                단순비교 epsilon비교
size_5_1    0.9                  0.8999999999999999   Cross    UNDECIDED
size_5_2    8.9                  0.1                  Cross    Cross
size_13_1   0.3                  14.700000000000008   X        X
size_13_2   7.499999999999997    7.5                  X        UNDECIDED
size_25_1   4.9                  4.899999999999999    Cross    UNDECIDED
size_25_2   52.9                 0.1                  Cross    Cross
```
